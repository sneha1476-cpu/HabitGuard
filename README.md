# HabitGuard

AI-driven personalized smartphone behavior and digital wellness app.

## Phase 1 included
- Flutter-ready project structure
- Real Android UsageStatsManager integration via Kotlin MethodChannel
- Dashboard for actual device usage data
- Firebase-ready placeholders
- Python FastAPI/ML-ready server structure

## Open
1. Install Flutter SDK and Android Studio.
2. Run `flutter create .` from this folder if platform scaffolding is needed.
3. Run `flutter pub get`.
4. Open the folder in Android Studio.
5. On an Android device, grant Usage Access permission when prompted.

Firebase files/credentials are intentionally not included. Add your own Firebase configuration later.
